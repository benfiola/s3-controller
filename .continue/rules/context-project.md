# (Rule) Project

This repository provides a Kubernetes controller that administrates S3 resources in a backend-agnostic way.

**Single entry point:** CLI at `cmd/s3-controller/main.go`, containerized via Goreleaser
(`.goreleaser.yaml`, `.goreleaser.Dockerfile`).
